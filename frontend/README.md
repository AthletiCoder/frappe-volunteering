# Volunteering frontend (Frappe UI SPA)

Vue SPA for Budget Health + Advance Portal. App overview: [../README.md](../README.md).

```bash
cd apps/volunteering/frontend
yarn
yarn build
bench --site <site> clear-cache
```

Routes (after build):

- `/volunteering/budget-health`
- `/volunteering/advances`

My Expenses shortcuts and sidebar links open these URLs directly.
